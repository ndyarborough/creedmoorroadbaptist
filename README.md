# Creedmoor Road Baptist Church

Website for Creedmoor Road Baptist Church in Raleigh, NC. Service times, ministries, events, and contact.

## Stack

React 18 with TypeScript, built with Vite. Material UI for components, Tailwind CSS for layout, Firebase for hosting and backend. React Router for navigation.

## Running locally

```bash
npm install
npm run dev        # Vite dev server
npm run build      # type-check + production build
npm run lint
npm run deploy     # build + deploy to Firebase Hosting
```
